# 窗口区域颜色反转工具

Windows 10/11 的轻量级托盘工具。运行 `run_window_invert.bat`（或直接执行
`pythonw window_invert.py`）后，右下角托盘图标会提供：

- **选择反相窗口**：列出当前可见的顶层窗口，选中后立即开始反相。
- **开启/关闭反相**：暂停或恢复当前窗口的反相。
- **退出**：关闭覆盖层并退出。

工具使用系统 `PrintWindow` 将目标渲染到离屏位图，再用 GDI `NOTSRCCOPY` 进行实时反相，
不向目标窗口注入代码；
覆盖层为不可激活、鼠标穿透窗口。每帧按 Z 序把目标窗口被上层窗口遮挡的矩形扣除，
因此遮挡窗口不会被覆盖。窗口移动、缩放、最小化、关闭和多显示器坐标会在后台自动更新。

只依赖 Python 3.9+ 标准库，无需安装第三方包。
